# Portfolio Red Team Release Plan

This release upgrades the portfolio from strong positioning to visible proof.

## Release goals

1. Create two clear visitor pathways: employers and organizations.
2. Add an AI Workflow Enablement services page with a controlled-pilot offer.
3. Turn flagship project pages into proof-first case studies.
4. Make the résumé directly downloadable or viewable without an email request.
5. Add an evidence and privacy standard that centralizes disclosure language.
6. Improve technical credibility with repository links, architecture, testing, and status evidence.
7. Add baseline SEO, social-sharing, accessibility, and automated quality checks.

## Flagship proof hierarchy

1. AI Workflow Enablement
2. AliOS / Unseen Lifeline
3. Inventory Truth Ledger

Additional work remains available but should not compete equally for first attention.

## Acceptance criteria

- A first-time visitor can identify Ali's professional value in under 15 seconds.
- Employers can reach experience, résumé, and selected case studies in one click.
- Prospective clients can reach the service offer, pilot scope, and contact path in one click.
- Each flagship case study includes visible proof: architecture, sample artifacts, tests, screenshots, or a reproducible repository.
- Claims are labeled as professional work, prototype, architecture, synthetic demonstration, or future work.
- No private, employer-confidential, medical, legal, housing, financial, or identifying source material is published.
- Automated checks validate links, HTML structure, and accessibility-sensitive markup before release.
