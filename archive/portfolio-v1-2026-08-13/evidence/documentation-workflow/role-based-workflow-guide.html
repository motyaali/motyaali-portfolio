Role-Based Deliverable Workflow Guide

A public-safe reconstruction showing how a complex deliverable process can be organized around the user’s next action, required inputs, authority, and handoff condition.

How the guide is designed

  • Organize by role and action rather than software menus.
  • State what information is required before the user starts.
  • Separate review authority from approval and publication authority.
  • Show the exact condition that starts the next stage.
  • Treat permissions and identity failures as workflow blockers with an owner and next action.

Public evidence boundary

This artifact reconstructs the operating logic of professional documentation work registered in the portfolio evidence system. It does not reproduce employer or client records, project names, screenshots, internal systems, or the exact approval matrix.
