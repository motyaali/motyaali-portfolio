# AI Workflow Enablement Public MVP Proof Pack

This folder contains inspectable evidence for the Meeting Intelligence MVP.

## Contents

- `synthetic-meeting-notes.md`: fictional source meeting designed to test explicit decisions, missing dates, dependencies, temporary rules, unassigned ownership, risk, and human-only controls
- `reference-reviewed-record.md`: expected example after human review
- `acceptance-tests.md`: test matrix and manual validation procedure
- `governance-boundary.md`: automation authority, review requirements, public data boundary, and production-pilot requirements
- `administrator-runbook.md`: operating, validation, change-control, and migration guidance

## Working demonstration

Open `../../demos/meeting-intelligence.html` through the public site or a local web server.

## Claim boundary

The public implementation demonstrates the operating workflow and evidence design. It uses deterministic proposals and synthetic data. It does not establish production model accuracy, integration reliability, measured client outcomes, compliance, or autonomous decision authority.
