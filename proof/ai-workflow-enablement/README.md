# AI Workflow Enablement Evidence Pack

This folder contains inspectable evidence for the AI Workflow Enablement applied case study and its Meeting Intelligence review prototype.

## Contents

- `synthetic-meeting-notes.md`: fictional source meeting designed to test explicit decisions, missing dates, dependencies, temporary rules, unassigned ownership, risk, and human-only controls
- `reference-reviewed-record.md`: expected structured example after accountable review
- `acceptance-tests.md`: manual and automated validation matrix for the meeting and document-intake demonstrations
- `governance-boundary.md`: proposal authority, human-review requirements, public-data boundaries, and production-adaptation requirements
- `administrator-runbook.md`: operation, validation, change control, release, and organizational-adaptation guidance

## Working demonstrations

- Open `../../demos/meeting-intelligence.html` to inspect source-preserving proposal review, correction, approval, rejection, and evidence export.
- Open `../../demos/document-intake.html` to inspect routine group confirmation, duplicate handling, missing-information control, classification review, and controlled routing.

## Claim boundary

The public implementation demonstrates workflow design, deterministic reference behavior, human-review controls, evidence preservation, and browser interaction using fully synthetic data. It does not establish production model accuracy, enterprise integration reliability, measured organizational outcomes, compliance with a specific employer's policies, or autonomous decision authority.
