# Project Coordination Controls Evidence Pack

## Classification

**Applied case study | Portfolio reconstruction | Synthetic data**

This folder contains the inspectable records behind the Construction Project Coordination Controls case study. It is designed to demonstrate current project-coordination practice without presenting academic work as client work or publishing confidential source material.

## Start here

1. [`dashboard.html`](dashboard.html) presents the decision-ready weekly coordination view.
2. [`project-baseline.md`](project-baseline.md) defines the scenario, scope, authority, milestones, and operating rules.
3. The CSV registers provide the source records behind the dashboard.

## Role boundary

The Project Coordinator in this case may:

- prepare and organize records
- verify administrative completeness
- route information to authorized reviewers
- track ownership, status, next action, and due date
- document decisions and approval history
- escalate missing information and emerging risks

The Project Coordinator does not independently approve:

- contracts or commitments
- technical design direction
- changes in scope, price, or time
- invoices or payments
- final acceptance or closeout

## Evidence rules

- All names, dates, organizations, vendors, costs, and project records are fictional.
- The scenario is reconstructed from coursework and expanded to reflect current understanding.
- The records demonstrate controls and judgment, not prior employment authority.
- No employer, agency, client, contractor, or class-team source document is published here.
- Improvements are framed as practical controls within an established process, not as replacement systems.
