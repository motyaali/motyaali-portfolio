# Motya Ali Portfolio

A static, accessible professional portfolio generated from controlled public copy and publication rules.

## Publish with GitHub Pages

1. Create a public repository named `motyaali-portfolio`.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main`, and select `/ (root)`.
4. Save. GitHub will publish the site at `https://motyaali.github.io/motyaali-portfolio/`.

## Privacy and evidence rules

- Do not upload private archives, raw databases, credentials, employer-confidential files, legal/medical/housing records, or proprietary datasets.
- Preserve the maturity labels used throughout the site.
- Use synthetic, sanitized, reconstructed, or representative examples when original materials cannot be shared.
- Run a privacy and link review before public launch.
